# ロボットは、日常会話や複雑な指示でも物を運べるか

※このREADME.mdは生成AIを用いて作成しました。

## 概要

本プロジェクトでは、ロボットアームが指示の言い方の違いをどの程度理解し、正しく物体を運べるかを検証する。

MuJoCoによる物理シミュレーション環境でFranka Pandaロボットを動作させ、Gemini Robotics-ERに画像と指示文を入力する。モデルが認識したブロックと皿の位置をもとにロボットを制御し、指示の種類による成功率の違いを比較する。

## 実験内容

以下の3種類の指示を比較する。

| 指示の種類 | 内容 |
|---|---|
| 普通の指示 | 色を用いて対象を直接指定する |
| 日常会話の指示 | 指示語、省略、言い直しなどを含む話し言葉で指定する |
| 複雑な指示 | 順序、相対位置、除外条件、距離などを用いて指定する |

画像と目標を固定し、指示の表現だけを変えて実験する。各指示について、ブロックの把持から皿への配置までを実行し、正しいブロックを正しい皿に置けた場合を成功とする。

2. Google AI Studio等で取得したGemini APIキーを、Colabの「シークレット」に `GEMINI_API_KEY` という名前で登録する。
3. Notebookからシークレットへのアクセスを許可する。
4. 上から順番にセルを実行する。
5. 実験終了後、Notebook内で生成される集計結果や動画を確認する。

## 評価方法

主な評価指標は、目標とするブロックを正しい皿に配置できたかどうかによる成功率である。また、認識結果や把持・運搬・配置の各段階で発生した失敗も分類し、指示の種類による違いを確認する。

## 制約と今後の課題

本実験はシミュレーション環境での検証であり、実際のロボットや現実の物理環境で同様の性能が得られるとは限らない。今後は、実環境における照明条件、物体の形状・重量・摩擦、ロボットと物体の接触などの物理的な制約を考慮した検証が必要である。
